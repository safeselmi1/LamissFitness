# Lamiss Fitness

Public site for Lamiss Fitness, phase 1. This is a TanStack Start app (React, Vite, TypeScript, Tailwind CSS) with shadcn/ui configured.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

The dev server listens on [http://127.0.0.1:43123](http://127.0.0.1:43123).
