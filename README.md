# Lamiss Fitness

Public site for Lamiss Fitness, phase 1. The repo is split into a frontend app and a backend.

## Frontend

TanStack Start (React, Vite, TypeScript, Tailwind CSS) with shadcn/ui configured.

```bash
cd frontend
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Backend

`backend/` is the API, database, jobs, and edge functions. It is not started in phase 1.
