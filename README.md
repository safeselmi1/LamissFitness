# Lamiss Fitness

Public site for Lamiss Fitness, phase 1. UI lives in `front/`. Data and jobs live in `back/`.

## Front

TanStack Start (React, Vite, TypeScript, Tailwind CSS) with shadcn/ui configured.

```bash
cd front && npm install && npm run dev
```

The dev server listens on [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Back

`back/` is the API, database, jobs, and edge functions. It is not started in phase 1.
